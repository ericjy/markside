# GitHub-style Alerts

Use alerts to make important information stand out without interrupting the rest of a document.

## Note

> [!NOTE]
> Markside renders alerts in Preview and Split modes while keeping their source as portable Markdown.

## Important

> [!IMPORTANT]
> Open the extension settings and enable **Allow access to file URLs** before viewing local files.

## Warning

> [!WARNING]
> Review an Unsaved Draft before navigating away from the current file.

## Tip

> [!TIP]
> Use `Cmd+P` on macOS or `Ctrl+P` on Windows and Linux to switch files quickly.

## Caution

> [!CAUTION]
> Confirm the target path before overwriting a file that changed outside Markside.

## Rich content

Alert bodies can contain multiple paragraphs and ordinary inline Markdown.

> [!NOTE]
> The first paragraph can include **emphasis**, `inline code`, and [links](https://github.com).
>
> A second paragraph stays inside the same alert.
