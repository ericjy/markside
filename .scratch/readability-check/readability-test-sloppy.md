# The office move and the other thing

We're moving to a new space, tentatively on October 18. Timing depends on the landlord, the network install, and desk assignments, so some details below may still shift. This update covers what's changing and how access and requests will work. If something isn't covered here, ask — that's better than guessing.

## What is changing

- **New space:** Fourth floor of the Annex.
- **Move date:** Tentatively October 18.
- **Pack personal items by:** October 16.
- Facilities will move monitors, chairs, and shared equipment.
- The new space has fewer meeting rooms, so book one only when you need it.

### Desks

Desks will be assigned next week. Until then, keep using your current desk — you don't need to move your computer yourself.

## Access and requests

Badge access and the access plan are related but not the same thing: depending on whether the roster is final, one gets done before the other.

- If you're on the roster, you should get access automatically.
- If you're not on the roster but need access, that's an exception — request it through the usual route.
- Visitors use a different route.

If a door or elevator doesn't work for someone who should have access, they should contact us so we can fix it.

The SSO group feeds the access list (ACL), except for temporary passes and the old-pass migration. IT says that cutover is on track; Facilities has flagged some blockers. We don't expect this to hold anything up, but it could, so please do your part.

Don't submit your information on the access form until it's confirmed ready — last week's linked version may be outdated. We'll share the current link soon.

### If something doesn't work

Ask the right team: IT or Facilities, depending on whether it's a badge issue or a building issue. If you're not sure which, ask either one and we'll route it. Raise problems as early as you can — late requests take longer to resolve and create more work for everyone.

## The kitchen

Several pieces still need to come together: the seating map, the roster, the access process, the network install, box labels, and vendor coordination. Some are done; others are waiting on each other. Work from the latest plan, and watch for an update if it changes. Managers should share what they know with their teams and raise open questions with us.
