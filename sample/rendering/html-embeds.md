# HTML Embeds

An image line that names a local `.html` file shows that page in place.

## Interactive diagram

![Save flow: Markside finds the file through a saved folder, or asks you to choose its folder](./html-embeds.assets/save-flow.html)

Click the two buttons above the diagram. In Split, type in the source and the
selected path stays.

## Sandbox

![Sandbox check: network requests from this embed are blocked](./html-embeds.assets/sandbox-check.html)

Clicking the navigate button should leave the embed in place or show an error
inside it; the page must not open example.com.
