# Keyboard Shortcuts

Quick reference for tools I use daily.

## Terminal

| Shortcut | Action |
|----------|--------|
| `Ctrl+R` | Reverse history search |
| `Ctrl+L` | Clear screen |
| `Ctrl+A` | Move to start of line |
| `Ctrl+E` | Move to end of line |

## VS Code

| Shortcut | Action |
|----------|--------|
| `⌘P` | Quick open file |
| `⌘⇧P` | Command palette |
| `⌘B` | Toggle sidebar |
| `⌘/` | Toggle comment |

## Chrome DevTools

| Shortcut | Action |
|----------|--------|
| `⌘⌥I` | Open DevTools |
| `⌘⌥J` | Open Console |
| `⌘⌥C` | Inspect element |
