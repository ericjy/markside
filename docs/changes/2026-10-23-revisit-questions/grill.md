# Revisiting previous questions

This interview records the conversation that established the change.

### Q1. How should previous questions appear?

The user proposed rendering each previous question in the same card style,
collapsed by default and read only, with a button to reopen it.

> **Your decision:** Use collapsed Question Cards for previous questions and provide a way to revisit them.

### Q2. What should revisiting do?

The proposed flow was an expandable card showing the original question and
chosen answer. Revisit question opens a composer prefilled with the saved answer.
Saving creates a pending Review Comment, and sending asks the agent to reconsider
the question and dependent decisions. The archived decision remains visible until
the agent processes the revision.

> **Your decision:** The user accepted this proposal with "let's do it".
