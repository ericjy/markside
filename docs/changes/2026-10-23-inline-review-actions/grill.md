# Inline Review actions decisions

## Q1. Keep a banner or open the Review sidebar?

The screenshot showed a large gap between the waiting message and Finish review. The user agreed to keep the banner as one compact row instead of opening the sidebar automatically.

## Q2. Can the reviewer still comment, and send with the sidebar closed?

The user asked that the message explain that commenting can continue and that sending remain available with the sidebar closed. The agreed waiting row is “Your agent is waiting. Keep commenting, or finish.” followed by Finish review. When unsent Review Comments exist, replace the message with a comment count and the action with Send review. The user approved implementation in chat.

## Q3. How should the row look?

After seeing the implementation, the user asked about a different background, a smaller button, and a floating position. The approved refinement keeps the row below the toolbar, with a subtle neutral tint and bottom border, a 28px button with smaller text, and a roughly 44px row. The text and button stay together, wrapping when necessary.
