# Keep interview source readable

Archived questions should be easy to read in source and other Markdown renderers.
Write their complete content as ordinary Markdown and let Markside generate
collapsed cards and expandable comparisons in Preview. Preserve support for
existing HTML-wrapped questions and the existing Review handoff.

This changes interview instructions, question rendering, and the current test
document. It does not migrate historical design records. No open questions remain.
