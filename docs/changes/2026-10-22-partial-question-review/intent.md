# Send partial Question Card Reviews

The footer currently appears only once every question is answered. Reviewers
need to see their progress and send the answers they have without completing
the whole round. They also need to clear a selected option before sending so
that question remains unanswered.

Show the footer throughout an active agent Review, count answered questions,
and allow sending with unanswered questions remaining. This affects Question
Cards in Preview and Split Preview. Keep the existing Review handoff and send
conditions. There are no open questions.
