# Readable interview source

### Q1. Should archived questions contain HTML disclosures in source?

The user reported that the Full question and nested Compare tradeoffs HTML
wrappers make the interview difficult to read in source and other Markdown
renderers. The accepted proposal was ordinary Markdown headings, decision
callouts, context, options, recommendations, and comparison tables, with Markside
generating the folding controls in Preview. Existing wrapped questions remain
supported. The user accepted the proposal with "do it".

> **Your decision:** Keep folding in Markside's rendering, and write new interview archives and comparisons as ordinary Markdown.
